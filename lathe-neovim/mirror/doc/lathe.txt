*lathe.txt*   Java language server for Maven and Gradle projects — Neovim client

                                                        *lathe* *lathe.nvim*

Lathe is a Java language server for Maven and Gradle projects: code
intelligence, diagnostics, and run/test/debug, built on the JDK's own
compiler. This plugin is the Neovim client; the server is resolved and
installed by your build.

==============================================================================
REQUIREMENTS                                            *lathe-requirements*

  - Neovim 0.12+, on Linux or macOS
  - The Java Treesitter parser: `:TSInstall java`
  - A Maven, Gradle or OpenJDK project set up once with |:LatheInit|; this
    runs a Lathe build, which installs the server and creates the `.lathe/`
    workspace.

==============================================================================
SETTING UP A PROJECT                                    *:LatheInit*

:LatheInit [maven|gradle|openjdk]
    Sets Lathe up for the build around the current file. Walks up to the
    build's root and asks you to confirm it (edit the path to correct it). A
    Maven or Gradle build that does not register Lathe gets it from outside,
    without changing the project's files; one that does just builds. An
    OpenJDK checkout runs Lathe's OpenJDK goal once the JDK is built. The
    server attaches when the build ends. Run it again to move the project to
    this client's Lathe version; |:LatheSync| refreshes the workspace.

==============================================================================
SETUP                                                   *lathe-setup*

Call the setup function once, e.g. in your plugin config: >lua
    require('lathe').setup()
<
Without it, only indentation loads and the language server is not registered.

For `setup()` options, the full feature/endpoint reference, and a suggested
keymap set, see the guide:
  https://github.com/ag-libs/lathe/blob/main/docs/guide/editors/neovim.md

==============================================================================
FORMATTING                                              *lathe-formatter*

The formatter is the project's own, not an editor setting. On Maven, Lathe
runs the formatter the project's Spotless configuration names. Otherwise,
declare it in `lathe-style.json` at the project root: >json
    { "formatter": { "engine": "google", "version": "1.28.0" } }
<
The next build or `:LatheSync` resolves its jars; restart the server to use
it. Engines: `google`, `aosp`, `palantir`, `eclipse`, `command`,
`command-file`, `none`. See the installation guide:
  https://github.com/ag-libs/lathe/blob/main/docs/guide/installation.md

Report issues against the monorepo (this repository is a generated mirror):
  https://github.com/ag-libs/lathe
